# LunaWindow web app

Static Vite + React + TypeScript app. It reads cached JSON only (no backend, no live NASA request) and
implements the visibility analysis of `docs/data-contract.md` section 4 in `src/analysis/`.

## Commands

Run from `web/`:

| Command | What it does |
|---|---|
| `npm install` | Install dependencies |
| `npm run dev` | Dev server on the real dataset in `public/data/` (written by the pipeline) |
| `npm run synthetic` | Write the synthetic test dataset to `public/data-synthetic/` (git-ignored) |
| `npm run dev:synthetic` | Generate synthetic data, then run the dev server on it (`VITE_DATA_DIR=data-synthetic`) |
| `npm test` | Vitest unit tests (analysis, golden vectors from `../fixtures/analysis-golden.json`, projection, start clamping, wording) |
| `npm run build` | Type-check (`tsc -b`) and build to `dist/` |
| `npm run test:e2e` | Playwright flow test against the real dataset (starts its own dev server on port 4179) |
| `VITE_DATA_DIR=data-synthetic npm run test:e2e` | The same flow against synthetic data (run `npm run synthetic` first) |
| `node scripts/screenshots.mjs http://localhost:5173/ screenshots light` | Desktop and phone screenshots of a running dev server (`dark` for dark mode) |

Playwright needs its browser once: `npx playwright install chromium`.

## Data

- `VITE_DATA_DIR` picks the folder under `public/` (default `data`). The app loads `manifest.json`, then each
  site file when it is selected.
- When `manifest.synthetic` (or a site's `synthetic`) is true, a permanent banner says the numbers are synthetic.
- `public/data/` and `../fixtures/` are generated by the pipeline. Do not edit them here.

## Layout

- `src/contract/types.ts`: the contract's TypeScript shapes, copied verbatim.
- `src/analysis/`: pure functions (visibility analysis, projection, start-window clamping, formatting, wording).
- `src/components/`: UI. Charts are hand-written SVG.
- `tests/unit/`, `tests/e2e/`: Vitest and Playwright.
